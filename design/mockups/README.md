# Theme mockups

Snapshots of the artboards on the Claude Design canvas "Vibes Fund Theme Mockups" (https://claude.ai/artifact/TAqu1fAGSiaPshGNC3yKM5). All of them use the same sample data (`../sample-data.json`).

These `.dc.html` files are Claude Design artboards. They render inside the canvas, not as standalone web pages. To view or edit them, open the canvas link. `canvas.json` records the board layout.

| File | Direction | Status |
| --- | --- | --- |
| `MainV3.dc.html` | **A v3. Mood Ring Capital**, v2 with more charm | **Current lead.** Includes the halftone mood colors, the "Ahead or behind, day by day" chart, the rewritten investor letter and the Chairman's portrait |
| `MainV2.dc.html` | A v2. Mood Ring Capital, rebuilt on the Not AI rules | Superseded by v3 |
| `Main.dc.html` | A v1. Mood Ring '75 (cream and Fraunces) | Superseded; fails the Not AI rules |
| `Prospectus.dc.html` | B v1. Old Money Prospectus (Sentimental Value Partners) | B v2 still to be built on the rules doc spec |

| `CableTV.dc.html` | D. Cable Finance TV (Hot Take Holdings), first pass | Parked |
